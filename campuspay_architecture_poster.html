PAYMENT LIFECYCLE

8 PHASES
①
PRE-CONDITION (ONLINE)
Server generates 10 ECDSA tokens → delivered to student app via HTTPS → stored in flutter_secure_storage → wallet balance synced.
②
QR SCAN
Student scans vendor printed QR → reads merchant_id + soundbox_ble_id → app pre-connects to SoundBox BLE beacon in background.
③
AMOUNT + PAYLOAD
Student enters amount → app picks token → marks USED → generates signed payload {token_id, merchant_id, amount, timestamp, nonce, payer_sig} → deducts from wallet → writes SQLite.
④
DUAL TRANSMISSION
Simultaneously: emits 18–22kHz FSK burst via speaker + broadcasts BLE advertisement — both carry same signed payload.
⑤
SOUNDBOX RECEIVES
Mic catches ultrasonic burst OR BLE scanner catches advertisement (whichever first) → decodes payload.
⑥
LOCAL VERIFICATION
ECDSA verify using pre-loaded server public key → timestamp ±5m check → nonce check → expiry check → all pass ✅.
⑦
DOUBLE CONFIRMATION
SoundBox: "CampusPay se ₹80 mila" 🔊 + screen shows ✅. Student phone: signed receipt screen + receipt QR.
⑧
RECONNECT + RECONCILE
Student app syncs debit ledger → SoundBox syncs credit log → server matches token_id on BOTH sides → fraud checks pass → merchant settled → CampusCoins awarded.
